# Proyecto 4: Segmentación de Postulantes UNI

## 📋 Descripción del Proyecto
Este proyecto tiene como objetivo analizar y segmentar a los postulantes de la Universidad Nacional de Ingeniería (UNI) utilizando técnicas de análisis de datos y machine learning. El desarrollo principal se ha realizado en Python, buscando identificar patrones y perfiles dentro del conjunto de datos.

## 📂 Estructura del Repositorio

El proyecto está organizado de la siguiente manera para facilitar su revisión y ejecución:

*   **`/data/`**: Contiene los archivos de origen en formato Excel (`.xlsx` o `.xls`) necesarios para alimentar el código.
*   **`/docs/`**: Carpeta de documentación principal.
    *   📄 `Proyecto_4_Segmentacion_Postulantes_UNI.pdf`: Informe final del proyecto que detalla la metodología, hallazgos, y conclusiones de la segmentación.
*   **`/resultadocodigo/`**: Contiene los resultados de la ejecución del código exportados en formato PDF. Este es un respaldo técnico preparado en caso de que existan problemas de entorno o dependencias al intentar ejecutar los scripts de Python.
*   `[Script Principal de Python]`: (e.g., `main.py` o los Jupyter Notebooks correspondientes).

## 🛠️ Tecnologías Utilizadas
*   **Lenguaje:** Python
*   **Gestión de Datos:** Pandas (para lectura de archivos Excel y manipulación de datos)
*   *Nota: Revisa el archivo de requerimientos si existe para conocer las versiones exactas de las librerías adicionales utilizadas (ej. Scikit-Learn, Matplotlib, Seaborn).*

## 🚀 Instrucciones de Uso

1.  **Preparación de los Datos:** Asegúrate de que los archivos de Excel se encuentren correctamente ubicados dentro de la carpeta `/data/`.
2.  **Ejecución:** Ejecuta el script principal de Python de tu preferencia desde la raíz del proyecto.
3.  **Resultados Alternativos:** Si no dispones del entorno configurado para ejecutar Python, dirígete directamente a la carpeta `/resultadocodigo/` para visualizar los outputs del código en formato PDF, o consulta el informe consolidado en `/docs/Proyecto_4_Segmentacion_Postulantes_UNI.pdf`.
